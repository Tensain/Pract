Дневник допускается заполнять в печатном виде, «живыми» должны быть только подписи руководителя и студента, оценка за практику. Каждый «раздел» дневника должен быть с новой страницы (инд. задание, план-график, дневник, отзыв), заполняется таким образом, чтобы эти «разделы» вместились на одну страницу. 

Скан дневника с подписями студента вместе с отчетом подгружается в электронный университет.

Требования к заполнению раздела ДНЕВНИК предполагают ежедневное внесение записей с понедельника по субботу, за исключением выходных и праздничных дней. Каждая запись должна содержать конкретную информацию о выполненных работах за соответствующий день, включая вид деятельности, используемые методы и инструменты, а также достигнутые результаты. Допускается повторение содержания записей не более чем для трех дней подряд при условии выполнения однотипных задач. В случаях, когда характер работ требует большего количества одинаковых записей, необходимо предоставить дополнительные пояснения в примечаниях.

Описание должно быть четким и информативным. Например, корректной записью будет: "15.07.2024 – Изучение архитектуры Transformer. Анализ статей по оптимизации BERT для маломощных устройств. Тестирование предобученной модели на датасете GLUE". При этом не допускаются избыточно повторяющиеся формулировки без указания конкретных деталей работы, такие как несколько дней подряд с одинаковой записью "Чтение литературы" без уточнения изучаемых материалов и этапов работы.

В разделе "ПЛАН (РАБОЧИЙ ГРАФИК) ПРАКТИКИ" необходимо поэтапно отразить перечень работ с указанием конкретных временных промежутков продолжительностью от 1 до 4 дней для каждого вида деятельности. Для каждого периода в обязательном порядке формулируется четкое задание, определяющее содержание работы: изучение научной литературы по выбранной тематике исследования, разработка программного модуля или компонента системы, проведение тестирования функциональности разработанного решения, анализ полученных результатов и другие виды работ, соответствующие целям практики.
